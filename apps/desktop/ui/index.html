TU ESPACIO PRIVADO

Protege tus archivos.
Sin salir de tu dispositivo.

Cifrado local y backups protegidos. Tus archivos originales se conservan: Vault nunca los elimina automáticamente.

Versión de desarrollo Incluye cifrado de archivos y carpetas con manifiesto cifrado. No conserva carpetas vacías ni admite enlaces simbólicos; cada archivo está limitado a 32 MiB por el motor en memoria. El backup .nqb contiene las claves, no los archivos .nqx ni las carpetas protegidas: conserva ambas copias por separado. Los selectores nativos permiten elegir archivos y carpetas. No la uses como única copia de datos importantes.

VAULT DESBLOQUEADO

Operaciones seguras

Cifrar archivo

El archivo cifrado se crea junto al original con extensión .nqx.

Restaurar archivo

El destino debe ser nuevo; nunca se sobrescribe silenciosamente.

Cifrar carpeta

Los nombres y las rutas se guardan en un manifiesto cifrado. No modifica los originales.

Se propone un nombre dentro de la carpeta elegida; puedes editar la ruta.

Restaurar carpeta

La carpeta de destino debe ser nueva. Se validan el manifiesto y cada objeto cifrado.

Se propone una carpeta nueva dentro de la ubicación elegida.

Crear backup

Protege el contenedor y sus claves; no incluye los archivos .nqx ni las carpetas protegidas.

Restaurar backup

Restaura las claves en un vault nuevo. Los archivos cifrados se conservan aparte.
