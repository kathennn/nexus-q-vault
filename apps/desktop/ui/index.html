TU ESPACIO PRIVADO

Protege tus archivos.
Sin salir de tu dispositivo.

Cifrado local y backups protegidos. Tus archivos originales se conservan: Vault nunca los elimina automáticamente.

Versión de desarrolloYa permite cifrar carpetas con un manifiesto cifrado y nombres opacos para los objetos. No conserva carpetas vacías ni admite enlaces simbólicos; cada archivo está limitado a 32 MiB por el motor en memoria. El backup .nqb contiene las claves, no los archivos .nqx ni las carpetas protegidas: conserva ambas copias por separado. No la uses como única copia de datos importantes. Las rutas se introducen manualmente; aún no hay selector nativo.

VAULT DESBLOQUEADO

Operaciones seguras

Cifrar archivo

El archivo cifrado se crea junto al original con extensión .nqx.

Restaurar archivo

El destino no debe existir; nunca se sobrescribe silenciosamente.

Cifrar carpeta

Guarda archivos con nombres opacos y rutas protegidas en un manifiesto cifrado. No modifica los originales.

Restaurar carpeta

La carpeta de destino debe ser nueva. Se restauran los archivos del manifiesto autenticado.

Crear backup

El backup protege el contenedor y sus claves; no incluye los archivos .nqx. Usa una contraseña independiente.

Restaurar backup

Restaura las claves en un vault nuevo. Los archivos .nqx se conservan aparte.
